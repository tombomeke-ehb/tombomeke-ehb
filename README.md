## Featured Projects

### [NexusInfra](https://github.com/Tombomeke-Studios/NexusInfra)
A self-hostable platform to deploy and run Docker servers across several machines from one panel.

- React and Vite dashboard, Node services, API gateway, orchestrator and per-host agents over RabbitMQ
- Role-based sharing (viewer, operator, admin, owner) and teams
- Vitest test suite and CI via GitHub Actions
- **Stack:** TypeScript, React, Node.js, Prisma, RabbitMQ, Docker

### [FinVault](https://github.com/Tombomeke-Studios/FinVault)
A full-stack banking platform: web dashboard, mobile app and event-driven microservices.

- React web dashboard and an Expo mobile app
- Express and Prisma services (accounts, wallets, invoices) behind an API gateway
- JWT with refresh-token rotation, rate limiting, Vitest tests and GitHub Actions pipelines
- **Stack:** TypeScript, React, Expo, Express, Prisma, RabbitMQ

### [NexusNotes](https://github.com/Tombomeke-Studios/NexusNotes)
A self-hosted, markdown-first note app with end-to-end encrypted vaults and sync.

- Tauri desktop app with a React and TypeScript UI, Go sync service, PostgreSQL, Docker Compose
- **Stack:** TypeScript, React, Tauri, Go, PostgreSQL, Docker

### [Contract Companion](https://github.com/tombomeke-ehb/Contract-Companion)
AI-assisted contract analysis platform.

- Upload contracts (PDF/Word) → OCR → AI summary
- Highlights risky clauses and key terms, with a dashboard of deadlines
- **Stack:** Vue 3, Node.js, Google Cloud Document AI

### 📦 [ReadmeSync](https://github.com/tombomeke-ehb/ReadmeSync) (NuGet CLI tool)
A .NET **CLI tool** that auto-generates README/ROADMAP files by scanning your codebase.

- Published on NuGet
- Used by external developers
